# 变更记录

## 0.2.4（2026-09-18）

安全加固 + 适配 ZCode 3.12.3 新版配置布局：

- **fix（安全）——allow 白名单命令替换绕过**：用户自定义 allow 规则下，
  `ls $(危险载荷)`、反引号替换、进程替换 `<()`/`>()` 整段被白名单放行、载荷不经
  任何审查（默认规则表无 allow 规则，开箱不受影响）。修复：新增命令替换构造检测
  （`hasCommandSubstitution`），allow 命中复合命令仍交逐段逻辑；单段含替换构造时
  抑制该 allow 并继续向后扫描 deny/ask（后续 deny/ask 命中载荷文本仍生效）；
  逐段全 allow 但任一段含替换构造时整体降级 LLM 审查
- **provider 解析适配新版配置**：读取优先级调整为 `~/.zcode/v2/provider_config.json`
  （新版布局：providerConfigRules 规则，凭据 access.apiKey 与自定义接入点
  api.baseUrl/api.type 的权威源）→ `~/.zcode/v2/config.json`（provider 表：enabled
  标记与模板型 provider 完整定义）→ `~/.zcode/cli/config.json`（旧布局兜底），
  合并为统一 provider 表：规则按 providerId 覆盖合并（凭据/接入点/模型顺序优先取
  规则）、providerName 注册别名、无接入点的模板型规则跳过、无 enabled 标记时按
  规则 providerOrder 回落；GUI 的 provider/模型下拉改用同一统一表（临时文件传递，
  窗口关闭即删）；测试环境变量新增 `AUTO_REVIEW_PROVIDER_CONFIG`
- **平台声明（描述级）**：当前 ZCode 插件清单无 platform 字段（经程序包逆向确认），
  在 plugin.json / marketplace.json description 中显式声明平台边界（审查内核全平台；
  对话框与图形配置仅 Windows）；`/auto-review gui` 非 Windows 报错文案改为引导
  命令式配置；对话框回落日志区分"非 Windows / 锁屏 / 基础设施故障"
- 测试：单元 +4（31 项）——命令替换检测、单段替换绕过防护、provider 规则合并、
  providerOrder 回落；场景 20 项、冒烟 14 项、PS 语法校验全绿
- 版本号统一 0.2.4（plugin.json / marketplace.json / package.json 三处同步）

## 0.2.3（2026-09-05）

提示词 GUI 化 + 脚本内容随命令送审：

- **安全策略提示词编辑器**：`/auto-review gui` 设置窗口新增提示词分区与独立编辑器
  子窗口——显示当前全文（数据目录优先、回落出厂默认）、就地编辑、恢复出厂内容、
  保存前输出契约字段校验（decision/risk_level/analysis/risks/scope 缺失警告确认）、
  UTF-8 无 BOM 落盘立即生效；与 `/security-prompt` 命令完全等价
- **脚本内容随命令送审**（`inspect_scripts`，默认关闭）：python/python3/py/node/deno/
  bun/bash/sh/zsh/dash/ruby/perl/pwsh 调用、powershell -File、cmd /c、裸脚本路径均提取
  脚本引用（`-c`/`-e` 内联与 `-m` 模块排除）；相对路径按 hook 输入 cwd 解析；
  单文件上限 `script_max_bytes`（默认 16000，钳制 1000~100000）、最多 3 个文件、
  二进制跳过、失败附注；附件块独立预算追加进送审载荷，审查基于脚本实际内容；
  附件摘要参与缓存键加盐（脚本改动自动失效重审），无附件时与旧键完全兼容；
  任何异常只降级为"不附加"，绝不影响决策保守性
- **GUI 加固**：审查范围区新增脚本送审开关与上限输入；PS 侧配置加载改逐键合并，
  旧版 settings.json 缺新键时保留默认值（防止保存悄悄写坏）；窗口 760×760→760×876
- **fix**：提示词编辑框改折行 + 仅纵向滚动——出厂提示词含超长行，不折行会把横向
  滚动范围撑到数倍于框宽（超长滚动条、内容与框宽不匹配）；折行后宽度恒与编辑框一致
- **出厂提示词**：审查对象节补充脚本附件块说明与"按脚本实际内容"裁量要求
- 测试：单元 +6（27 项）、场景 +4（20 项）全绿；GUI 实机验证通过
- 版本号统一 0.2.3（plugin.json / marketplace.json / package.json 三处同步）
