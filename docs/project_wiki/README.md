# auto-review 项目 Wiki

> ZCode 自动审查权限插件：上下文干净的安全子 agent 代替用户初筛权限外请求——安全的自动放行，不安全的在插件审查对话框中携带分析、风险点、影响范围由用户裁决。

作者: hh-zyb ｜ 版本: 0.2.5 ｜ 技术栈: Node.js ≥ 18（零第三方依赖）+ PowerShell WinForms GUI + ZCode 插件体系（hooks / commands）

## 功能特性

- **模拟第五种权限模式**：内置自动编辑模式 + PreToolUse hook 门卫，安全的命令自动放行
- **上下文干净的安全子 agent**：只看本次工具调用 JSON（+ 可选脚本附件），不接触对话历史，免疫对话内提示注入
- **插件审查对话框**：现代化深色窗口（风险徽章/命令卡片/三段式分析），点击即裁决、无超时等待；默认关闭
- **图形配置界面**：`/auto-review gui`，与命令式配置完全等价，全组件统一深色风格；含提示词编辑器
- **确定性危险规则层**：正则先行，deny/ask/allow 三动作；复合命令逐段审查防白名单绕过
- **脚本内容随命令送审**（默认关闭）：python/node/bash 等调用的脚本文件内容自动附加送审，按实际内容审查
- **可定制审查策略**：提示词在 GUI 编辑器全文显示、就地修改，立即生效
- **provider 复用**：默认跟随主 agent，可指定其他 provider / flash 级快模型
