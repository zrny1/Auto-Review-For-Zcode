# 代码地图

> 模块 → 文件 → 核心函数 → 职责。文件头均有统一格式注释。

## src/common.js —— 配置中心

| 导出 | 职责 |
|------|------|
| `g_data_dir`（内部） | 数据目录：`AUTO_REVIEW_DATA_DIR` 环境变量优先，否则 `~/.zcode/auto-review` |
| `getDataDir()` | 返回数据目录并按需创建 |
| `logWrite(level, module, msg)` | 统一日志（时间戳[级别][模块]），512KB 轮转，失败静默 |
| `readJsonFile(path, fallback, module)` | 防御式 JSON 读取，ENOENT 静默回落 |
| `writeFileAtomic(path, content)` | 临时文件 + rename 原子写 |
| `*_FILE` 常量 | 数据目录与出厂默认的全部路径 |

## src/settings.js —— 配置加载

| 导出 | 职责 |
|------|------|
| `loadSettings()` | 出厂默认 + 数据目录覆盖（类型校验）+ 数值钳制（timeout 5s~45s 等） |
| `saveSettings(s)` | 原子写 settings.json |
| `loadDangerRules()` | 规则编译（im 标志）；非法正则跳过并 WARN，序号保持原始位置 |
| `loadRawDangerRules()` / `saveDangerRules(r)` | 原始规则表读写（ctl 命令用） |
| `loadSecurityPrompt()` | 数据目录提示词 → 出厂默认 → 最小兜底串 |

## src/provider.js —— provider 解析与调用

| 导出 | 职责 |
|------|------|
| `resolveProvider(settings)` | `~/.zcode/v2/config.json`（回退 cli）解析：显式指定（兼容 `builtin:` 前缀）或首个 enabled；apiKey/baseURL/model 校验 |
| `callLlm(info, system, user)` | anthropic（`/v1/messages`）或 openai（`/chat/completions`）；AbortController 超时；单次不重试 |
| `ProviderError` / `LlmError` | 面向日志的错误类型（消息不含密钥） |

## src/reviewer.js —— 决策管线

| 导出 | 职责 |
|------|------|
| `reviewToolUse(hook_input)` | **主入口**，六层编排，保证不抛异常 |
| `normalizeToolName()` | ApplyPatch→Write 等别名归一 |
| `buildRuleText()` | Bash→命令全文；Write/Edit→目标路径；空输入不送审 |
| `matchDangerRules()` | 规则层：数组顺序首个命中生效，deny/ask/allow |
| `computeCacheKey()` / `readCachedDecision()` / `writeCachedDecision()` | 稳定序列化（键排序）sha256 键；TTL 惰性清理；上限 500 条 |
| `extractJsonObject()` | 平衡花括号扫描（字符串内 `}` 不截断），容忍围栏 |
| `parseVerdict()` | 输出契约解析；**deny 收敛为 ask**；非法输出抛错 |
| `formatVerdictReason()` | 三段式 reason：风险级别+分析 / 风险点列表 / 影响范围 |

## src/decision.js —— 输出协议（唯一客户端耦合点）

| 导出 | 职责 |
|------|------|
| `emitDecision({action, reason})` | pass→空输出 exit 0；其余→`{hookSpecificOutput:{hookEventName,permissionDecision,permissionDecisionReason}}`；`AUTO_REVIEW_OUTPUT_STYLE=simple` 可切换简化风格 |
| `emitCrash(msg)` | 内部崩溃最终防线：stderr + exit 2（阻断） |

## src/hook_main.js —— hook 入口

`readStdinAll()` 全量读 stdin → JSON 容错（空/非法→pass）→ `reviewToolUse()` → `emitDecision()`；
未捕获异常 → 日志 + `emitCrash`。

## src/ctl.js —— 控制 CLI

`init / status / set <k> <v> / rules list|add|remove|test / prompt show|path|reset`；
键白名单 + 类型/区间校验 + 正则自校验；错误走 stderr + exit 1。
