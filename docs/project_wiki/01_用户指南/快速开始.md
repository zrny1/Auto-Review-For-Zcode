# 快速开始（安装与启用）

## 前置条件

- ZCode 客户端（支持插件与 PreToolUse hooks）
- Node.js ≥ 18（`node --version` 可用即可，无需 npm install——插件零第三方依赖）
- 一个可用的 ZCode provider（API Key 型；默认直接复用主 agent 当前的）

## 一、安装插件（本地 marketplace）

1. 打开 ZCode **设置 → 插件管理**，切到 **发现（Discover）** 标签页；
2. 点 **+** 添加本地 marketplace，选择**本项目根目录**（如 `D:\Demo\DemoSuperVisionForZcode`，
   根目录的 `.zcode-plugin/marketplace.json` 是市场清单，声明了其中的 auto-review 插件）；
3. 在插件列表中找到 **auto-review**，点击 **Get/安装** 并启用；
4. 验证：命令面板输入 `/` 能看到 `/auto-review`、`/danger-rules`、`/security-prompt` 三个命令即安装成功。

## 二、开启自动审查

```
/auto-review on
```

然后把 ZCode 权限模式切到**自动编辑模式**（这是自动审查的基座：文件编辑不打扰，命令由安全子 agent 把关）。

## 三、验证生效

让主 agent 执行一条普通命令（如 `git status`）：

- **不弹审批框、直接执行** → 门卫已工作（查看审查记录：`~/.zcode/auto-review/review.log`）；
- 主 agent 执行 `rm -rf /` 之类的命令会被规则层直接拦截。

> 注意：安全子 agent 审查每次命令会引入 1~5 秒延迟。嫌慢可换快模型：
> `/auto-review set model glm-5.3-flash`，并用 `/danger-rules add allow '...'` 给高频安全命令加白名单。

## 数据目录

所有运行时数据在 `~/.zcode/auto-review/`（Windows 即 `C:\Users\<你>\.zcode\auto-review\`）：

| 文件 | 用途 |
|------|------|
| settings.json | 运行时配置（开关、审查工具、provider/model、超时、缓存） |
| danger_rules.json | 危险规则表（初始不存在时用出厂 14 条规则） |
| security_prompt.md | 安全子 agent 提示词（自定义后生成） |
| cache.json | 审查结论缓存 |
| review.log | 审查日志（含每条决策与来源层） |
