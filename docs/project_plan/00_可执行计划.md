## 风险与应对

| 风险 | 应对 |
|------|------|
| hook 输出 JSON 字段名与客户端严格 schema 不一致 | 决策输出集中在 decision.js 单点，集成验收时按 ZCode 日志校正 |
| LLM 审查延迟 1~5 秒 | 默认只审查 Bash、结果缓存、支持配置快模型 |
| LLM 超时/报错 | 一律兜底 ask（转人工），绝不在错误时放行 |
| userConfig 环境变量注入未验证 | V1 不依赖 userConfig，全部运行时配置走数据目录 settings.json，由命令管理 |
